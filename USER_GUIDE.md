# Инструкция пользователя CVAT Progress

## Цель сервиса

CVAT Progress предназначен для загрузки и просмотра информации о ходе разметки из CVAT. Сервис объединяет задания по проектам, показывает их статусы и разметчиков, а также добавляет сведения о количестве размеченных кадров для каждой метки.

## 1. Загрузка списка заданий

Сначала подготовьте файл `jobs_info`:

1. Откройте в CVAT вкладку **Jobs**.
2. Выполните экспорт через **Export jobs to CSV**.
3. На главной странице CVAT Progress выберите полученный CSV-файл в блоке **jobs_info**.
4. Нажмите **Загрузить в базу данных**.

Файл должен содержать столбцы:

- `ID` — Job ID;
- `Task ID`;
- `Task Name`;
- `Project Name`;
- `Assignee`;
- `State`.

После загрузки записи добавляются в базу данных. Если сочетание `Task ID` и `Job ID` уже существует, сведения о задании обновляются.

## 2. Выбор проекта

После загрузки `jobs_info` над таблицей появляется список проектов из файла. Нажмите на название проекта, чтобы открыть его отдельную страницу.

На странице проекта отображаются только относящиеся к нему задания. Для возврата к общей таблице нажмите **Все проекты**.

## 3. Загрузка информации о разметке

Форма **annotations_info** доступна только на странице конкретного проекта:

1. Перейдите на страницу нужного проекта.
2. Выберите CSV-файл в блоке **annotations_info**.
3. Нажмите **Загрузить файл**.

CSV должен содержать столбец `Job_id`. Все столбцы, расположенные после `Job_id`, воспринимаются как названия меток. Значения в них должны содержать количество размеченных кадров.

Пример:

```csv
Job_id;Автомобиль;Пешеход;Светофор
501;120;35;8
502;95;21;4
```

Данные сопоставляются со строками проекта по `Job_id`. Пустые значения, пустые или повторяющиеся названия меток и повторяющиеся `Job_id` не допускаются.

При повторной загрузке `annotations_info` предыдущие столбцы и значения выбранного проекта полностью заменяются содержимым нового файла. Данные других проектов не изменяются.

## 4. Работа с таблицей

Доступны следующие возможности:

- поиск по содержимому таблицы;
- фильтрация по нескольким статусам, проектам и разметчикам одновременно;
- фильтрация по нескольким Job ID, введённым через запятую;
- удаление отдельных строк;
- скачивание таблицы в CSV.

Если фильтры не установлены, в CSV выгружается вся открытая таблица. При активных фильтрах выгружаются только видимые строки.
